# Defensive Security

Repositório dedicado aos meus projetos e laboratórios de segurança defensiva.

Os projetos abordam conceitos relacionados a operações SOC, monitoramento e análise de eventos, segurança de endpoints, Active Directory, IAM e infraestrutura Windows.

## Conteúdo

- **Homelabs** — Ambientes desenvolvidos para praticar configuração, monitoramento, detecção e segurança de infraestrutura.
- **SOC Investigations** — Investigações e análises de alertas e incidentes de segurança.

Cada projeto possui sua própria documentação com detalhes sobre o ambiente, ferramentas utilizadas, procedimentos realizados e resultados obtidos.
